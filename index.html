Cortège

Appli de sécurité pour les manifestations, pour Android. Elle marche sans réseau : pas de compte, pas de serveur.

Version d'essai. Code non relu de l'extérieur, fiches Droits et Secours en brouillon non relu. Ne t'y fie pas encore si tu risques gros. À savoir avant d'installer.
Télécharger Cortège Version 0.1.0-essai, 53 Mo, pour Android

Installer en 4 étapes

  1. Appuie sur le bouton jaune. Ton téléphone télécharge le fichier.
  2. Ouvre le fichier téléchargé : dans la notification, ou dans le dossier « Téléchargements ».
  3. Android dit que ton téléphone n'est pas autorisé à installer des applis depuis cette source : c'est normal, l'appli n'est pas dans un magasin. Appuie sur « Paramètres », active « Autoriser depuis cette source », reviens en arrière, puis appuie sur « Installer ». Si Google Play Protect affiche un avertissement, choisis d'installer quand même.
  4. Ouvre Cortège et choisis ton code. Le mode d'emploi t'explique la suite pas à pas.

À savoir avant d'installer

  • Aucune personne extérieure n'a relu le code.
  • Les fiches Droits et Secours sont des brouillons écrits par un assistant, que personne n'a relus. Pour un doute sur un droit, demande à un avocat. Pour un geste de secours, appelle le 15 ou le 112.
  • Essayée sur deux téléphones Android seulement. Pas de version iPhone.
  • Rien n'est envoyé sur internet : l'appli n'a même pas le droit de se connecter.

Vérifier le fichier (facultatif)

Après le téléchargement, l'empreinte SHA-256 du fichier doit être celle-ci :

ecccc6914e901ecdf1045384cbc0830af08389a569684f05756027a1381cb593

Une fois l'appli installée, l'écran « Partager l'appli » affiche l'empreinte courte 4e8a f9b7 6a37 f23d : si tu passes l'appli à un proche, il doit voir la même. Le détail est sur la page de cette version.
